Process for updating repo

Step 1: **Pull** to get any updates

Step 2: **Staging** (adding the files to the queue to send to the repo)
Best way to do this...in the Terminal

git add .

Step 3: **Commit** (sending the file info to the repo to commit to an update)
In the Terminal

git commit -m "a brief message indicating what you're sending"

Step 4: **Push** files to the repo
In the Terminal

git push

If you get ahead on branches

git reset HEAD~1

(you can change the 1 to other values if you are ahead by more than one commit...
or just rerun the command a bunch)
